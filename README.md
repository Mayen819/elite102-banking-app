# Elite 102 Banking App

A fully functional banking application built with Python, Tkinter, and SQLite.

## Features
- Create bank accounts with an initial deposit
- Deposit funds into any account
- Withdraw funds with overdraft protection
- Check account balance
- View all accounts in a table
- Full transaction history per account

## Setup Instructions

### Requirements
- Python 3.12 or higher
- python-tk@3.12

### Installation

1. Clone the repository:
   git clone https://github.com/Mayen819/elite102-banking-app.git

2. Navigate into the folder:
   cd elite102-banking-app

3. Install tkinter if on Mac:
   brew install python-tk@3.12

4. Run the app:
   python3.12 vault.py

## How to Use
1. Click "Create Account" to open a new account
2. Use the Account ID shown to deposit, withdraw, or check balance
3. Click "List Accounts" to see all accounts and their IDs
4. Click "Transaction History" and enter your ID to see all activity
